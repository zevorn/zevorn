## 基本气质

Zevorn 的中文表达应该真实、具体、克制，平淡中带一点温和。读者感受到的不是作者在展示文采，而是有人愿意把事情慢慢讲清楚，也愿意看见其他人的处境和付出。

不要把话说得太满。保留事实本来的边界，也保留一点没有完全想明白的空间。

温和不等于模糊，克制也不等于没有判断：

- 已经确认的事实，直接说；
- 仍有范围和条件的判断，把范围说清楚；
- 属于个人感受的内容，用第一人称承担；
- 不确定的地方，诚实保留不确定性；
- 必须明确的技术结论和安全要求，不要为了语气温和而弱化。

## 用词的克制与温度

### 常用的程度词

在确实存在程度或不确定性时，可以自然使用：

- `我觉得`、`我想`；
- `大概`、`可能`、`未必`；
- `有一点`、`不太`、`还好`；
- `慢慢`、`很多时候`、`到现在`；
- `初步看`、`目前看`、`在这个范围内`。

这些词的作用是让判断更准确，不是给每句话加缓冲垫。不要把确定事实写成犹豫，也不要在一个句子里叠加多个程度词。

### 谨慎使用绝对词

下面这些词需要足够强的事实支持：

- `一定`、`必须`；
- `从来`、`永远`；
- `彻底`、`完全`；
- `唯一`、`最`；
- `毫无疑问`、`显然`、`必然`。

如果证据只支持局部结果，就写局部结果；如果只是个人选择，就写“我现在更愿意怎么做”，不要替所有人下结论。

### 温和从哪里来

温和主要来自对人和细节的注意：

- 写清楚谁做了什么，而不是只说“她很辛苦”；
- 看见一件事同时存在的两面，不急着替读者统一感受；
- 表达感谢或欣赏时，先给出动作、时间、物件和身体感受；
- 自我修正时不逞强，不把正确答案写成对别人的训话；
- 可以有一点玩笑，但玩笑之后要回到真实的人和事情。

避免用大量赞美、抒情形容词或人生道理制造“温暖”。理想的感觉是平实、体谅，让人读起来比较舒服。

温和不能依靠替人物补充心理。即使“她大概是为了让我放心”听起来很合理，只要素材没有提供，也不要写成事实。可以保留原话、动作和停顿，让读者自己感受。

## 逻辑词与转折

逻辑词不是个人口头禅，每一个词都要承担真实作用。

| 逻辑词 | 更适合承担的作用 |
|---|---|
| `后来` | 推进时间，或者带出状态发生变化 |
| `终于` | 结束一段真实的等待，让叙事突然加快 |
| `好在` | 在压力之后短暂松一口气，不把结果夸大 |
| `但` | 做比较清楚的转折，常放在夸奖、自信或玩笑之后 |
| `不过` | 做温和补充、限定或修正，不推翻前面的整段意思 |
| `其实` | 从表面印象、玩笑或标签拉回更真实的判断 |
| `当然` | 承认一个显而易见的侧面事实，或者做简短插话 |
| `只是` | 缩小前面的判断，把语气落到一个较轻、较具体的修正上 |
| `却` | 放在同一句或相邻句中表现事实与预期之间的反差，力度比单独起段的 `但` 更缓 |
| `不管怎么说` | 收回岔开的叙述，回到真正想说的人或判断 |
| `可` | 在后半段承担情绪上的转弯，前面需要有足够事实铺垫 |
| `到最后`、`反而` | 写真实发生的结果反转，不预先制造人生道理 |

使用时注意：

- `但` 比 `不过` 更硬，`不过` 更像轻轻扶正；
- `其实` 不是通用转折词，它通常带有“前面只是表面，下面才是我真正想说的”；
- `只是` 适合把结论收小，`却` 适合让反差留在具体句子里，两者都比强行拔高更克制；
- `当然` 不要成为句首填充词；
- `终于`、`好在` 前面必须真的存在等待、压力或风险；
- 相邻几个段落不要为了变化而轮流使用不同逻辑词；
- 如果调整句子顺序已经能表现转折，就不必再加词。

## 句子、断句与标点

### 一个句子主要完成一件事

场景句可以短一些，解释原因和机制时可以适当拉长。不要把事实、感受、评价和结论全部塞进同一个长句。

适合断句的位置通常是：

- 动作完成；
- 时间发生变化；
- 叙述从事实转向感受；
- 语气从玩笑转回认真；
- 一个原因已经解释清楚；
- 需要让读者停一下的情绪转折。

### 用句号重新起步

句号不只是语法结束，也负责调整呼吸。一个具体场景写完后，可以用下一段重新开始，不必用“因此”“与此同时”“值得一提的是”把所有内容粘在一起。

逗号适合同一口气里的连续动作和补充。冒号、分号、括号只在内容真的需要分层时使用。

引号常用来放：

- 真实说法或原话；
- 临时称号；
- 带一点自嘲或玩笑的词；
- 需要与正文语气保持一点距离的网络表达。

不要把普通名词都加上引号。

## 段落与文章节奏

### 中文散文与公众号文章

一个段落通常承载一个动作、一个小场景、一个判断或一次转弯。

可以用独立短段承担：

- 等待之后的释放，例如 `好在最后赶上了。`
- 明确转折；
- 一句自嘲；
- 一个暂时停住的情绪；
- 结尾前最后一次回拉。

短段之后通常要回到动作或事实。不要把每句话都拆成一段，也不要连续使用很多只有一句话的“金句段落”。

个人散文可以有较多留白。技术文章要把同一个机制的解释放在一起，段落通常比散文更完整，不要照搬公众号散文的碎段节奏。

### 图片和公众号排版

图片应该放在场景、人物或阶段发生变化的位置，让读者自然停一下。图片附近的文字可以短一些。

从公众号复制出来的纯 `Image` 字样只是占位符，不属于正文，也不能当成个人风格证据。

### 标题与分节

个人散文不需要为了“结构清晰”强行增加小标题。只有当问题、时间阶段、机制或讨论对象真的变化时，才使用分节。

技术文章、教程和项目复盘可以使用标题、列表、表格和代码，但每一种结构都要解决真实的信息组织问题。

## 动作、细节与因果

人工改稿体现出几个明确偏好：

- 把抽象解释改成身体或动作，例如情绪 `推着我往前跑`；
- 时间不能悬空，写成 `住院那十多天`，让读者知道这段时间属于什么；
- 行为背后有可靠原因时，把机制补出来；
- 同一个细节只在最有因果作用的位置解释，不在前后重复；
- 赞美和情绪尽量放在细节之后。

写完一段抽象判断后，可以问：

1. 是什么动作让我得出这个判断？
2. 有没有一个时间、物件、数字或身体感受可以支撑它？
3. 这个原因是用户提供的事实，还是我自己补出来的？

只有来源明确时才能补充。

## 幽默的用法

可以使用当下的网络表达、自嘲、临时称号，或者稍微尖一点的口语。它们需要满足三个条件：

1. 从真实场景里自然长出来；
2. 只占一个短句、短段或局部插话；
3. 后面通过 `但`、`其实` 或具体事实回到正文。

例如“古希腊掌管……的神”这种说法可以偶尔使用，但不能把每一个生活片段都改成梗。较强的口语要考虑发布渠道和读者范围；用户已经明确提供的说法优先保留。

## 不同中文体裁

### 技术文章

- 从真实问题、现象、结果或工程决定进入；
- 中等长度段落解释同一个机制；
- 日志、命令、代码、数据和限制靠近对应判断；
- 可以保留常用英文术语，不为表面统一而生硬翻译；
- 语气克制，明确区分“观察到”“推测”“还没有验证”。

### 教程

- 按读者实际操作顺序组织；
- 每条命令说明用途和预期现象；
- 先给最小可运行路径，再补充变体；
- 不用散文式留白破坏可复现性。

### 个人散文

- 用时间、天气、动作、物件或人物进入；
- 让几个被选择的片段推动情绪变化，不求覆盖所有事情；
- 允许短段、留白和轻微自嘲；
- 把抽象感受落回普通生活；
- 结尾停在一个具体动作、画面或没有说满的承认上。

### 观点与复盘

- 先给产生判断的经历或反例；
- 对常见观点保持公平，不为了突出自己把别人写得简单；
- 写清楚条件、范围和例外；
- 最后说自己目前怎么选择，或者还有什么没有想清楚。

## 如何收尾

结尾不需要完成一次“升华”。

比较适合的落点是：

- 回到开头的人、天气、道路、物件或动作；
- 停在一个还没有完全解决的问题；
- 说清楚目前能确认的边界或下一步；
- 留下一句克制的愿望或承认。

人工修改中，`可我们的人生，已经被她轻轻地挪动了一下。` 后面的两句被删除了。这说明最有力量的情绪已经落下时，不需要再重复标题、解释成长或补一条对称的总结。

完成初稿后，找到最后一句真正有信息或情绪变化的话，尝试删掉它后面的全部内容。

## 改稿 checklist

把这份 checklist 当作方向提示，不做打分，也不要为了全部勾选而机械改写。

### 事实与依据

- [ ] 信息冲突时，是否采用了用户最近一次明确修正？
- [ ] 事实、转述、判断和不确定信息是否分开？
- [ ] 是否虚构了记忆、动机、对话、情绪、顺序或原因？
- [ ] 是否把一句话或一个动作擅自解释成“为了让谁放心”“说明谁已经意识到什么”？
- [ ] 抽象句能否改成有依据的动作、物件、数字、原因或结果？
- [ ] 同一细节是否放在最有作用的位置，而不是前后重复解释？

### 逻辑与转折

- [ ] 读者能否看清事情怎么发生、哪里变化、情绪或判断在哪里转弯？
- [ ] 每一个显式逻辑词是否真的承担了作用？
- [ ] 这里需要的是明确转折（`但`）、温和补充（`不过`），还是从表面拉回真实判断（`其实`）？
- [ ] `终于` 和 `好在` 前面是否真的有等待或压力？
- [ ] `不管怎么说` 是否真的结束了一段岔开的叙述？
- [ ] 不加逻辑词，只调整句子顺序，会不会更自然？

### 克制与温和

- [ ] 是否把任何判断说得超过了现有事实？
- [ ] 用 `大概`、`可能`、`未必`、`有一点` 或 `不太`，能否让程度更准确？
- [ ] 对已经确认的事实是否仍然说得直接，而不是把所有话都软化？
- [ ] 温和是否来自看见别人做了什么、付出了什么，而不是堆赞美和抒情词？
- [ ] 表达分歧或自我修正时，是否避免了炫耀、说教和强迫认同？
- [ ] 读完以后，语气是否平淡、体谅，让人舒服，而不是冷、满、硬或过分煽情？

### 声音与节奏

- [ ] 开头是否很快进入具体事件、人物、物件、问题或结果？
- [ ] 幽默是否来自真实场景，点到为止，后面仍然有实质内容？
- [ ] 标题、列表、短段和图片是否只在材料真正需要时使用？
- [ ] 独立短段是否承担了释放、转弯、风险或意识变化？
- [ ] 是否把 `Image`、平台模板、复制截断或错别字误当成了个人风格？

### 收尾

- [ ] 全文最有力量的最后一个动作、画面、承认、边界或下一步是什么？
- [ ] 它后面的句子是否都可以删掉？
- [ ] 结尾是否避免重复标题、再讲一遍道理，或把私人体验放大成普遍结论？
